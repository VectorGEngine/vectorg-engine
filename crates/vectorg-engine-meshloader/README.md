# VectorG Engine mesh loader

`vectorg-engine-meshloader` converts supported mesh files into shapes compatible with VectorG Engine and its underlying `parry3d` collision-detection library.

Supported Cargo features:

- `stl`: `.stl` files;
- `collada`: `.dae` files; and
- `wavefront`: `.obj` files.

VectorG Engine is derived from Rapier by Dimforge and preserves the original license and attribution.
